  12. `dashboards/dashboards.service.spec.ts`
  13. `payments/payments.controller.spec.ts`
  14. `payments/payments.service.spec.ts`
  15. `tasks/tasks.controller.spec.ts`
  16. `tasks/tasks.service.spec.ts`
- **Error Signature**:
  ```text
  Nest can't resolve dependencies of the TasksService (PrismaService). 
  Please make sure that the argument PrismaService at index [0] is available in the RootTestModule module.
  ```
- **Root Cause**:
  These test files were auto-generated by `@nestjs/cli` when generating modules. The tests invoke `Test.createTestingModule({ providers: [ServiceName] }).compile()`, but fail to provide a mock provider for `PrismaService` or other injected dependencies. Because `PrismaService` is required in the constructor, NestJS DI fails during compilation.

#### B. Enterprise Authorization DataScope Test Failures (1 Test Suite)
- **Failing Suite**: `auth/authorization-data-scope.spec.ts`
- **Failures**:
  1. `TypeError: Cannot read properties of undefined (reading 'findMany')`:
     In `DataScopeService.resolveDataScope()` (line 208), the service queries `this.prisma.permission.findMany(...)`. The mock object passed in the unit test failed to mock the `permission` model repository on `prisma`.
  2. `expect(received).toEqual(expected)` filter mismatch:
     ```text
     - Expected: { assignedCounselorId: 'counselor-1' }
     + Received: { OR: [ { assignedCounselorId: 'counselor-1' }, { assignedSeniorCounselorId: 'counselor-1' }, ... ] }
     ```
     `DataScopeService` was enhanced in Phase 4 to support hierarchical senior counselor and team queries via `OR` blocks, but the unit test assertion was not updated to reflect this enhancement.

#### C. Document Vault Watermark Test Failure (1 Test Suite)
- **Failing Suite**: `documents/documents-vault.spec.ts`
- **Failure**:
  ```text
  ERROR [DocumentWatermarkService] PDF watermarking failed: Failed to parse PDF document (line:0 col:66 offset=33): No PDF header found
  Error: Failed to parse PDF document (line:0 col:66 offset=33): No PDF header found
  ```
- **Root Cause**:
  The unit test passed an arbitrary text string buffer (`Buffer.from('dummy-content')`) into `watermarkPdf()`. Because `pdf-lib` strictly verifies valid PDF file headers (`%PDF-`), it threw a parsing exception.
